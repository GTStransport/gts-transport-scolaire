# Notice utilisateur GTS Connect

Cette notice donne les repères essentiels pour utiliser l'application selon le rôle de l'utilisateur.

Adresse de l'application : https://gestion-transport-scolaire.web.app

## Règles communes

- Utiliser uniquement son identifiant et son code personnel.
- Ne jamais partager son code d'accès.
- Vérifier les informations avant d'enregistrer une modification.
- Signaler toute erreur, anomalie ou accès inhabituel via le Centre Support.
- Ne consulter que les informations nécessaires à sa mission ou à son enfant.
- Après une première connexion avec un code temporaire, définir son accès personnel si l'application le demande.

## Parent

### Connexion

1. Ouvrir l'application.
2. Choisir l'accès parent.
3. Entrer l'identifiant ou le code fourni.
4. Finaliser la première connexion si un code temporaire est demandé.

### Accueil

L'accueil permet de voir les informations principales liées au transport de l'enfant :

- enfant(s) lié(s) au compte ;
- circuit, école et véhicule si renseignés ;
- chauffeur et convoyeuse associés ;
- messages ou alertes utiles ;
- demandes support en cours.

### Enfant(s)

Le menu `Enfant(s)` permet de consulter la fiche de l'enfant.

Le parent peut :

- consulter les informations utiles au transport ;
- compléter la fiche médicale / aide à la prise en charge ;
- modifier la fiche médicale si une information change ;
- consulter les personnes responsables et personnes autorisées si elles sont renseignées ;
- vérifier les informations de circuit et de prise en charge.

Les informations internes SPW sensibles ne sont pas affichées au parent.

### Fiche médicale

La fiche médicale doit être complétée avec les informations nécessaires à la sécurité pendant le transport :

- allergies ;
- affections médicales utiles à la prise en charge ;
- consignes importantes ;
- besoins particuliers pendant le trajet.

Après enregistrement, la fiche reste modifiable par le parent si une information doit être corrigée ou mise à jour.

### Messages

Le menu `Messages` permet d'échanger sur les informations liées au transport.

Bon usage :

- rester sur les sujets liés au transport scolaire ;
- éviter les données sensibles inutiles ;
- prévenir rapidement en cas d'information importante pour le trajet.

### Centre Support

Le Centre Support sert à demander de l'aide en cas de problème.

Le parent peut :

- créer une demande support ;
- recevoir un numéro de ticket ;
- recevoir une confirmation par e-mail ;
- suivre la réponse dans l'application ;
- recevoir la réponse du support par e-mail.

## Transporteur / Gestionnaire transport

### Connexion

1. Ouvrir l'application.
2. Choisir l'accès transporteur / gestionnaire transport.
3. Entrer l'identifiant et le code d'accès.
4. Vérifier que le tableau de bord affiche les données de l'organisation.

### Tableau de bord

Le tableau de bord donne une vue opérationnelle :

- véhicules hors service ou en retard ;
- chauffeurs ;
- nombre d'élèves ;
- alertes ou conflits de données ;
- accès rapide aux modules de gestion.

### Gestion transport

Le menu `Gestion transport` regroupe les données opérationnelles.

Le transporteur peut gérer ou consulter selon ses droits :

- chauffeurs ;
- convoyeuses ;
- véhicules ;
- écoles ;
- circuits ;
- affectations chauffeur / convoyeuse / véhicule ;
- informations de service utiles au transport.

### Élèves

Le menu `Élèves` permet de consulter les élèves liés au transport.

Le transporteur doit uniquement utiliser les informations nécessaires à l'organisation du trajet. Les informations sensibles réservées au SPW ne doivent pas être utilisées hors autorisation.

### Lieux de transfert

Le menu `Lieux de transfert` permet de suivre ou gérer les transferts prévus, selon les droits du compte.

À vérifier :

- lieu ;
- horaire ;
- véhicule ;
- chauffeur ;
- convoyeuse ;
- élèves concernés.

### Messages

Le transporteur peut suivre les messages opérationnels et les communications liées au transport.

### Accès & sécurité

Le menu `Accès & sécurité` permet de gérer les accès autorisés selon le périmètre du transporteur.

À faire régulièrement :

- désactiver les comptes inutilisés ;
- remplacer les codes temporaires ;
- vérifier les rôles affectés ;
- ne pas créer de compte partagé.

### Support

En cas de problème technique ou de donnée incohérente, créer une demande via le Centre Support avec un sujet clair et le contexte utile.

## Chauffeur

### Connexion

1. Ouvrir l'application.
2. Choisir l'accès chauffeur.
3. Entrer l'identifiant et le code fournis.

### Accueil

L'accueil chauffeur affiche les informations utiles au service :

- véhicule ou circuit associé ;
- école ;
- convoyeuse associée ;
- nombre d'élèves ;
- alertes ou messages importants.

### Élèves

Le chauffeur peut consulter les élèves liés à son circuit ou véhicule.

Informations utiles :

- identité de l'élève ;
- école ;
- circuit ;
- arrêt ou prise en charge si renseigné ;
- consignes nécessaires au transport ;
- fiche médicale utile à la sécurité, selon droits.

### Messages

Le chauffeur peut lire ou envoyer des messages liés au transport.

Bon usage :

- signaler les informations importantes ;
- éviter les messages personnels ;
- ne pas transmettre d'informations sensibles hors application.

### Transferts

Le chauffeur peut consulter les transferts qui le concernent.

Avant le trajet, vérifier :

- lieu de transfert ;
- horaire ;
- élèves concernés ;
- véhicule ou circuit prévu.

### Réglages

Les réglages permettent de vérifier les préférences du compte et certains paramètres d'affichage.

## Convoyeuse

### Connexion

1. Ouvrir l'application.
2. Choisir l'accès convoyeuse.
3. Entrer l'identifiant et le code fournis.

### Accueil

L'accueil convoyeuse affiche les informations utiles à l'accompagnement :

- circuit ;
- chauffeur associé ;
- véhicule ;
- école ;
- élèves liés ;
- alertes ou consignes importantes.

### Élèves

La convoyeuse peut consulter les élèves de son périmètre.

À vérifier avant le trajet :

- consignes de prise en charge ;
- besoins particuliers utiles au trajet ;
- informations médicales nécessaires à l'accompagnement ;
- personnes responsables ou autorisées si affichées.

### Messages

La convoyeuse peut communiquer sur les sujets liés au trajet et à l'accompagnement des élèves.

### Transferts

Les transferts affichent les changements ou lieux de prise en charge qui concernent la convoyeuse.

### Réglages

Les réglages permettent de vérifier les préférences du compte et l'affichage.

## SPW

### Connexion

1. Ouvrir l'application.
2. Choisir l'accès SPW.
3. Entrer l'identifiant et le code d'accès.

### Tableau de bord

Le tableau de bord SPW donne une vue de suivi :

- élèves ;
- transport ;
- messages ;
- transferts ;
- alertes ou anomalies ;
- données à vérifier.

### Élèves

Le SPW peut consulter les fiches élèves selon ses droits.

Le SPW peut accéder aux informations nécessaires au suivi administratif et à la sécurité, y compris certaines informations sensibles réservées au SPW.

### Informations sensibles

Les informations sensibles SPW sont réservées aux comptes autorisés.

Règles d'utilisation :

- ne renseigner que les informations nécessaires ;
- ne pas copier ces données hors application sans base autorisée ;
- ne pas communiquer ces informations aux parents si elles sont réservées au SPW ;
- signaler toute erreur d'affichage.

### Gestion transport

Le SPW peut consulter ou suivre les éléments liés au transport selon ses droits :

- circuits ;
- véhicules ;
- chauffeurs ;
- convoyeuses ;
- écoles ;
- transferts ;
- anomalies.

### Messages

Le SPW peut utiliser les messages pour le suivi opérationnel et administratif lié au transport.

### Support

En cas de bug, conflit de données ou demande d'assistance, utiliser le Centre Support.

Inclure si possible :

- le rôle utilisé ;
- l'élève ou le circuit concerné ;
- l'écran où le problème apparaît ;
- une description courte du problème.

## En cas de problème

Créer une demande dans le Centre Support.

Le support reçoit la demande sur `support@gts-connect.be`. Le demandeur reçoit une confirmation par e-mail avec un numéro de ticket, puis les réponses du support par e-mail.

Pour les demandes liées aux données personnelles ou au RGPD, utiliser `info@gts-connect.be`.
