# Procédures RGPD

Ce document décrit les procédures minimales à appliquer pour les demandes RGPD et les incidents de sécurité.

## Demande d’accès

1. Recevoir la demande via le contact données personnelles.
2. Vérifier l’identité du demandeur.
3. Identifier les données concernées.
4. Vérifier si des données de tiers doivent être masquées.
5. Préparer une réponse lisible.
6. Répondre dans le délai légal applicable.
7. Documenter la demande et la réponse.

## Demande de rectification

1. Vérifier l’identité du demandeur.
2. Vérifier la donnée contestée.
3. Corriger la donnée si elle est inexacte.
4. Informer les rôles concernés si la correction impacte le transport.
5. Documenter la correction.

## Demande de suppression

1. Vérifier l’identité du demandeur.
2. Vérifier les obligations de conservation.
3. Supprimer ou anonymiser les données supprimables.
4. Refuser uniquement si une obligation justifiée impose la conservation.
5. Répondre au demandeur.
6. Documenter l’action.

## Incident ou violation de données

Un incident peut être :

- accès non autorisé ;
- erreur d’affichage de données sensibles ;
- perte ou fuite de données ;
- compte compromis ;
- mauvaise attribution de rôle ;
- export transmis au mauvais destinataire.

Procédure :

1. Noter la date et l’heure de détection.
2. Identifier les données et personnes concernées.
3. Bloquer ou corriger immédiatement l’accès fautif.
4. Conserver les preuves techniques utiles.
5. Évaluer le risque pour les personnes.
6. Décider si une notification à l’autorité de protection des données est nécessaire.
7. Décider si les personnes concernées doivent être informées.
8. Documenter l’incident, les mesures prises et les suites.

## Analyse d’impact

Une analyse d’impact doit être envisagée car l’application traite :

- des données d’enfants ;
- des données de santé ;
- des informations de localisation ou de transport ;
- des rôles multiples avec accès différenciés ;
- des messages et historiques.

L’analyse doit couvrir :

- finalités ;
- nécessité et proportionnalité ;
- risques ;
- mesures techniques et organisationnelles ;
- risques résiduels ;
- décision de mise en production.
